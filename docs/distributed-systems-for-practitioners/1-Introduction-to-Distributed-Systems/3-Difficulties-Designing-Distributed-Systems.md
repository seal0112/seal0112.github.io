# 設計分散式系統的困難

## 網路非同步（Network Asynchrony）
網路沒辦法提供有力保證，比如 訊息最大傳輸時間，這種特性可能導致許多與非分散式系統不同的非直覺行為。比如
- 訊息傳輸時間極長
- 資料可能會不照順序送達，甚至無法送達

## 部分失敗（Partial Failures）
單機應用通常假設系統要麼正常運行，要麼整個伺服器崩潰。分散式系統中，這種部分失敗會帶來極大的複雜性，特別是在需要跨多個組件保持原子性的操作時。

系統必須確保某項操作要麼成功應用到所有節點，要麼不應用到任何節點，以維持一致性。

## 並發（Concurrency）
並發是指同時執行多個計算，這些計算可能會操作相同的資料。由於這些計算交錯執行，它會引入額外的複雜性，因為它們可能相互影響，導致意想不到的行為。

簡單應用程式會按照程式碼中定義的順序執行，不會受到並發執行的影響。
