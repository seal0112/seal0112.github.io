# 什麼是分散式系統

**分散式系統是將系統切分成多個元件，分散到不同網路上，元件之間透過網路互相傳遞資訊來玩成工作上的協調**

分散式系統的元件可以想像成多個軟體執行在不同的電腦上，並且負責不同的功能，功能可能有 Web Server, routers, Web browser 等等。


## 分散式系統的組成
分散式系統的核心部分可以分為兩大類：
1. 組成分散式系統的各個元件
    - 這些部分分散在不同位置，並由網路分隔。
2. 將這些元件分隔開的網路
    - 這個網路是元件之間的通信機制，讓系統內的各個元件能夠交換訊息。

## 為什麼需要分散式系統

### 1. 效能(Performance)

> **效能是指軟體系統或組件在及時性目標上的達成程度。**

#### 單台電腦的效能問題
- 硬體的物理限制會對單台電腦的效能產生上線
- 當性能提升到一定程度，單台電腦提升效能的成本很昂貴
#### 解決方案
- 透過 多台低規格電腦，可以實現與單台高規格電腦相同的效能。
- 分散式系統 使我們能夠以更低的成本獲得更好的效能。

### 2. 可擴展性(Scalability)
> **可擴展性是指系統、網路或程式執行的流程能夠處理不斷增長的工作量，或系統透過自動擴展來處理這種增長工作量的能力。**

#### 單台電腦的問題
- 軟體的價值主要來自 數據儲存 和 處理能力。
- 隨著系統的使用者數量增加，系統需要處理更多流量並儲存更大量的數據。
- 單台電腦的擴展能力有限，最終會遇到硬體性能的瓶頸（如前述效能問題）。
#### 解決方案
- 透過分散式系統，我們可以將數據存儲拆分到多台電腦上，並將計算負載分散處理，從而提高系統的可擴展性。

> 擴展性包含
> 1. 垂直擴展(Vertical scaling): 增加單一電腦的硬體來處理工作
> 2. 水平擴展(horizontal scaling): 增加多台電腦處理工作

### 3. 可用性(Availability)
> **可用性指的是系統在任務執行期間，能夠按照需求正常運行的機率。**

#### 單台電腦的問題
- 大多數軟體服務都需要 24/7 全天候執行
- 一個服務號稱可用性 99.999%，這個系統一年只能停機5分鐘。
- 硬體本身不可靠(硬體會壞需要替換)，依靠一台電腦來實現高可用性不現實。
#### 解決方案
- 冗餘（Redundancy） 是提高可用性的常見機制，將資料的儲存分散在多台電腦上，確保當一台電腦故障時，系統能夠快速切換到另一台運行中的電腦。
- 當數據分散存儲在多台電腦時，最終就形成分散式系統。
